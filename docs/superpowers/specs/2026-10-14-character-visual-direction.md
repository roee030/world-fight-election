# World Fight — Character Visual Direction

**Date:** 2026-10-14
**Status:** Concept review; no production sprite replacement yet.

## Shared target

Fighters must be identifiable from pose and silhouette before the player reads a name. The visual language combines forceful arcade key poses, readable movement arcs and compact controls. It remains original and preserves each character's existing identity, clothing palette and full-body sprite contract.

## First review board

![Fast, heavy and balanced fighter directions](../../design/concepts/2026-10-14-fighter-archetypes-v1.png)

The first board tests three roles:

- **Fast — Yair Lapid:** forward boxing line, narrow diagonal silhouette, fast blue-white slash trail and quick return to guard.
- **Heavy — Benny Gantz:** planted feet, broad shoulder mass, compressed wind-up and a large single impact shape.
- **Balanced — Naftali Bennett:** compact tactical guard, pivoting strike and circular cyan movement path.

## Production rules

- The board is direction art, not a shippable sprite sheet.
- Approved designs enter the existing transparent 4×3, 12-pose pipeline.
- Full body, feet and accessories remain visible. All source poses face screen-right.
- Motion trails and impact shapes are separate effects; they are not painted into every fighter frame.
- Faces stay illustrated and coherent with the body. Never paste a photographic face onto a generic body.
- A fighter's combat role must remain readable at the actual in-game height, without relying on text or colour alone.

## Review questions

1. Are the fast, heavy and balanced silhouettes distinguishable at gameplay scale?
2. Does each action line match the intended compact kit?
3. Are clothing, proportions and identity coherent with the current roster art?
4. Which direction should become the first full 12-pose production sheet?

## Generation record

Generated with the built-in ImageGen workflow using the current Lapid, Gantz and Bennett cards as identity/outfit references. Prompt requested a three-panel premium arcade-fighter concept board, one full-body action pose and two silhouette thumbnails per role, with no logos, weapons, blood, extra characters or photographic face compositing.
